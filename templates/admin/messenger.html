১ 🚀 মেটা পোর্টালে যুক্ত করার নিয়ম (Quick Setup Guide)

মেটা ডেভেলপার পোর্টালে আপনার অ্যাপ কনফিগারেশন করার জন্য নিচের স্টেপগুলো অনুসরণ করুন:

ধাপ ১: Phone Number ID
WhatsApp > API Setup থেকে Phone number ID কপি করে অ্যাডমিন সেটিংসে বসান।
ধাপ ২: WABA ID
API Setup থেকে WhatsApp Business Account ID কপি করে সেটিংসে বসান।
ধাপ ৩: Permanent Token
Business Manager > System Users থেকে পারমানেন্ট টোকেন তৈরি করে বসান।
ধাপ ৪: Webhook Callback
Webhook URL এবং Verify Token মেটা পোর্টালে বসিয়ে messages ফিল্ডটি সাবস্ক্রাইব করুন।

২ 🤖 স্মার্ট চ্যাটবট ও অটোমেটিক অর্ডার লিংক (২৪ ঘণ্টার ফ্রি উইন্ডো)

  • স্বয়ংক্রিয় অর্ডার লিংক: কাস্টমার হোয়াটসঅ্যাপে মেসেজ পাঠালে সিস্টেম তার মেসেজ থেকে Tracking ID (যেমন A0368762965B), Order ID (যেমন #12), অথবা মোবাইল নম্বর স্বয়ংক্রিয়ভাবে শনাক্ত করে অর্ডারের সাথে লিংক করে নেয়।
  • ফোন নম্বর ম্যাচিং: কাস্টমারের ফোন নম্বর (8801XXXXXXXXX বা 01XXXXXXXXX) ডেটাবেজের অর্ডারের সাথে মিললে চ্যাটবট স্বয়ংক্রিয়ভাবে অর্ডারের লাইভ ট্র্যাকিং লিঙ্ক, জুতার সাইজ, পরিমাণ ও বর্তমান স্ট্যাটাস দিয়ে ফ্রি-ফর্ম রিপ্লাই পাঠায়।
  • ২৪ ঘণ্টার নিয়ম (24-Hour Window): কাস্টমার কোনো মেসেজ পাঠানো মাত্রই পরবর্তী ২৪ ঘণ্টা পর্যন্ত আপনি তাকে সম্পূর্ণ ফ্রিতে সরাসরি কাস্টম মেসেজ পাঠাতে পারবেন।

৩ 📦 অর্ডার লাইফসাইকেল ৫-ধাপের অটো-নোটিফিকেশন (WhatsApp Cloud API)

অ্যাডমিন যখন ড্যাশবোর্ড বা অর্ডার ডিটেইলস পেজ থেকে একটি অর্ডারের স্ট্যাটাস পরিবর্তন করবেন, তখন কাস্টমারের হোয়াটসঅ্যাপে সাথে সাথে অটোমেটিক মেসেজ চলে যায়:

⚡
1. Payment Verified (পেমেন্ট নিশ্চিতকরণ)
পেমেন্ট অ্যাপ্রুভ করলে কাস্টমারকে জুতা প্যাকেজিং শুরু করার নোটিফিকেশন ও লাইভ ট্র্যাকিং লিংক পাঠায়।
📦
2. Packaged (জুতা প্যাকেজিং সম্পন্ন)
জুতা বক্স ও সিল প্যাক হয়ে গেট-আউট ও কুরিয়ার পিকআপের জন্য প্রস্তুত হওয়ার অ্যালার্ট পাঠায়।
🚚
3. Gate Out / Out for Delivery (রাইডার হ্যান্ডওভার)
কুরিয়ারের নাম (Steadfast/RedX/Pathao) ও কনসাইনমেন্ট নম্বরসহ ডেলিভারি রাইডার সংক্রান্ত মেসেজ পাঠায়।
🎉
4. Delivered / Received (ডেলিভারি সম্পন্ন)
জুতা ডেলিভারি হওয়ার পর কাস্টমারকে ধন্যবাদ জানানো ও ৩০ সেকেন্ডে স্টার রেটিং রিভিউ দেওয়ার লিঙ্ক পাঠায়।
🌟
5. Completed (অর্ডার ক্লোজ ও সমাপ্তি)
অর্ডার ভেরিফাই হয়ে সমাপ্তি ঘোষণা ও ভবিষ্যতে আরও জুতা কেনার জন্য সন্তুষ্টি বার্তা পাঠায়।

৪ 💬 অ্যাডমিন Omnichannel হাব ব্যবহারের নিয়ম

এই হাব থেকে আপনি একই সাথে Facebook Messenger এবং WhatsApp Business Cloud API-র লাইভ ইনবক্স হ্যান্ডেল করতে পারবেন:

  • কনভারসেশন ভিউ: বাম পাশের সাইডবারে সকল কাস্টমারের তালিকা ও তাদের সাথে লিংক থাকা অর্ডারের স্ট্যাটাস দেখতে পাবেন।
  • সরাসরি রিপ্লাই: যেকোনো কাস্টমারের চ্যাটে ক্লিক করে নিচে থেকে টাইপ করে সেন্ড বাটনে চাপলেই মেসেজটি কাস্টমারের মেসেঞ্জার বা হোয়াটসঅ্যাপ অ্যাপে চলে যাবে।
  • ম্যানুয়াল অর্ডার লিংক: কোনো কাস্টমার যদি নতুন কোনো নম্বর বা অ্যাকাউন্ট থেকে মেসেজ দেয়, তবে ওপরের ড্রপডাউন থেকে রিসেন্ট যেকোনো অর্ডারে সিলেক্ট করে "Link" বাটনে চাপলেই কথোপকথনটি স্থায়ীভাবে সেই অর্ডারের সাথে যুক্ত হয়ে যাবে।
